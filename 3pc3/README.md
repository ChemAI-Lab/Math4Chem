# CHEM 3PC3 — Mathematical Tools for Chemical Problems

Course website built with [Jupyter Book](https://jupyterbook.org/stable/build-and-publish/website/).

Mathematical tools for solving problems in chemistry: thermodynamics calculations,
multivariate calculus, linear algebra (systems of linear equations, matrix algebra,
eigenvalues and eigenvectors), and a brief introduction to model regression algorithms
such as neural networks. 

## Building the site locally

```bash
pip install jupyter-book
jupyter book start
```
